# Simulador de Erro Estacionário
## Descrição do Problema
Simula o tempo de assentamento de um sistema de controle do segundo ordem e calcula o erro estacionário para diferentes ganhos do controlador.
## Requisitos
- Simular a resposta de um sistema com polos em -2 e -3.
- Calcular o tempo de assentamento de 2%.
- Calcular o erro estacionário para rampa.
## Exemplo de Uso
Entrada: Ganho K = 1.0
Saída: Tempo de assentamento: 3.67s, Erro estacionário: 0.50
